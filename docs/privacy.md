# プライバシーと認証情報の扱い

Login Pilotの拡張機能は、HTTP/HTTPSページ内のフォームを監視します。未登録サイトの検出も必要なため、content scriptは対象の全サイトで動作します。保存済み認証情報の取得と自動送信は、利用者が登録したoriginだけで行います。

## 端末内に保存する情報

| キー | 内容 | 削除のタイミング |
| --- | --- | --- |
| `registeredOrigins` | 自動ログインを許可したoriginの一覧 | ポップアップで解除したとき、または拡張機能をアンインストールしたとき |
| `passkeyOrigins` | パスキーのログインボタンを自動で押す登録済みoriginの一覧 | 登録を解除したとき、またはアンインストールしたとき |
| `passkeyFrameOrigins` | 親サイトごとに許可したiframeの認証origin | 登録を解除したとき、別の認証originやトップレベル方式で上書きしたとき、またはアンインストールしたとき |
| `pendingSite` | 直近に検出した登録候補のorigin、検出日時、パスキーの場合は方式、利用後の検知かどうか、iframeの認証origin | 対象originを登録したとき、別の候補で置き換わったとき、またはアンインストールしたとき |
| `language` | 表示言語の設定（自動・日本語・英語） | 別の設定で上書きしたとき、またはアンインストールしたとき |

これらは`chrome.storage.local`に保存し、Chrome Syncによる同期や独自サーバーへの送信は行いません。ブラウザ・OSのバックアップなどによる扱いは、それぞれの設定に従います。フォームの全文、閲覧履歴の一覧、ID、パスワードは保存しません。

## 認証情報の流れ

1. 通常の自動入力では、Chromeが対象ページの入力欄に入れた値をcontent scriptが検査します。
2. ページ表示時や登録時の取得では、登録済みoriginに対し、Chromeの`navigator.credentials.get({ password: true, mediation })`を呼び出します。返されたID・パスワードはcontent script内で一時的に扱い、ページのフォームに入力します。
3. バックグラウンドへのメッセージにはoriginと操作情報を渡します。認証情報は渡しません。
4. 自動送信すると、フォームの値はサイト自身のフォーム処理・送信先に渡ります。送信先をLogin Pilotのサーバーへ変更する処理はありません。

未登録サイト、iframe、新規パスワード欄を持つフォーム、複数のパスワード欄があるフォームでは、保存済みパスワードによる自動ログインを行いません。手入力を開始したフォームも自動送信しません。フォームを識別するために既存の`autocomplete`がない入力欄へヒントを追加する場合があります。

拡張機能の「保存しない」は、認証情報を読み取らないという意味ではありません。認証情報は入力・送信のために一時的に扱います。ログインの送信先、ページの安全性、Googleパスワードマネージャーの保存・同期設定は、対象サイトとChromeの設定も確認してください。

## パスキー

パスキー方式を選んだ登録済みサイトでは、明示的なパスキーログインボタンを自動で押します。サイト自身がWebAuthnによる認証を開始し、本人確認とアカウント選択はChromeやOSが処理します。拡張機能はパスキーを取得・保存せず、秘密鍵、認証チャレンジ、署名、アカウント識別子、認証データ本体を読み取りません。認証リクエストの作成・変更や本人確認の省略も行いません。

パスキーの利用後に登録候補を表示するため、ページ側の`navigator.credentials.get()`に完了を観察する処理を追加します。呼び出しの方式、候補一覧の有無、返り値が認証レスポンスであることを一時的に判定します。元の引数、返り値、成功・失敗は変更しません。ページから拡張機能へ渡すのは利用を検知したという通知だけで、認証データは渡しません。この通知は登録候補のヒントとして扱い、利用者がポップアップで確認するまで登録を行いません。登録済みサイトのログイン方式は変更せず、方式を変えるには登録解除と再登録が必要です。サイト側でのログイン成功は確認しません。利用後に登録した場合は、その場で再認証せず次回から自動押下を許可します。

パスキーボタンの検出は、安全なページとiframeで行います。iframeでは親ページのoriginと認証ページのoriginを確認し、親ページからそのiframeの表示を確認します。利用完了の通知だけは、サイトが認証iframeを閉じた直後でも、直近15秒以内に確認できた同じ文書・親サイトの組み合わせから受け取れます。この例外で自動押下を許可することはありません。登録前に認証サイトをポップアップへ表示し、利用者が確認した組み合わせだけで自動押下します。操作先のタブ・フレーム・文書の識別子はバックグラウンドのメモリ内で一時的に扱い、永続保存しません。

キャンセル後の自動再試行とパスワードへの自動切り替えは行いません。パスキー方式のサイトではパスワードの取得・自動送信を停止します。メールアドレスや`autocomplete="username"`の入力欄では、入力が300ms落ち着いてから自動押下を試みます。アカウント入力以外のページ操作やEscapeキーで自動押下を停止します。利用検知の通知は登録候補のヒントとしてのみ扱い、自動押下を停止しません。

## 外部サービス

拡張機能には、独自サーバーへの通信、解析、広告、追跡コードはありません。GitHubとChromeウェブストアからの配布・更新は、それぞれのサービスを利用します。

紹介LPはCloudflareで配信し、Google FontsのCSSとフォントを読み込みます。LPを開いたときのIPアドレスなどのリクエスト情報は、CloudflareおよびGoogleのサービスで処理されます。このフォント通信は拡張機能からは行いません。

LPで選んだ言語は、LPの`localStorage`に`loginpilot.lp.language`として保存します。拡張機能の言語設定とは別で、ブラウザのサイトデータを消去すると削除されます。支援リンクを開いた場合は、Buy Me a Coffeeのサービスを利用します。

問い合わせ・脆弱性報告は[SECURITY.md](../SECURITY.md)を参照してください。
